**현재 상태**: 텍스트 기반만 구현됨
**요구사항**: "실시간 음성 기반 대화 기능" (CLAUDE.md Line 12)

**구현 작업**:
- [ ] Web Speech API 통합
  - Speech Recognition (음성 → 텍스트)
  - Speech Synthesis (텍스트 → 음성)
  - 실시간 음성 인식 UI

- [ ] 음성 대화 UX 설계
  - 마이크 활성화 버튼
  - 음성 입력 중 시각적 피드백 (파형 애니메이션)
  - 자동 음성 응답 (튜터 답변 읽기)
  - 음성/텍스트 모드 전환

- [ ] 음성 품질 최적화
  - 노이즈 제거
  - 발음 정확도 피드백
  - 다국어 음성 지원 (한국어/영어)

**예상 시간**: 3-4일
**기술 스택**: Web Speech API, MediaRecorder API
**성공 지표**:
- 음성 인식 정확도 > 90%
- 음성 응답 지연 < 1초
- 음성/텍스트 원활한 전환
