1️⃣  GitHub 저장소 생성 및 푸시 (5분)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: GitHub에서 새 저장소 만들기

   브라우저에서 다음 URL 접속:
   👉 https://github.com/new

   설정:
   ✓ Repository name: smarttuter
   ✓ Description: AI-powered tutoring platform for math and English
   ✓ Public 선택
   ✗ "Add a README file" 체크 해제 (이미 있음!)
   ✗ Add .gitignore 선택 안 함 (이미 있음!)

   "Create repository" 버튼 클릭


STEP 2: 터미널에서 GitHub에 푸시

   아래 명령어를 순서대로 실행하세요:
   (YOUR_USERNAME을 실제 GitHub 사용자명으로 변경!)

   git remote add origin https://github.com/YOUR_USERNAME/smarttuter.git
   git push -u origin main

   예시 (사용자명이 johndoe인 경우):
   git remote add origin https://github.com/johndoe/smarttuter.git
   git push -u origin main

   인증:
   - Username: GitHub 사용자명
   - Password: Personal Access Token (아래 참조)


Personal Access Token 생성 (처음 푸시하는 경우):

   1. https://github.com/settings/tokens 접속
   2. "Generate new token (classic)" 클릭
   3. Note: SmartTuter Deployment
   4. Expiration: 90 days
   5. 권한: ✓ repo (전체 선택)
   6. "Generate token" 클릭
   7. 생성된 토큰 복사 (ghp_로 시작)
   8. 푸시 시 Password로 사용

2️⃣  Anthropic API 키 발급 (3분)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Anthropic Console 접속

   브라우저에서 다음 URL 접속:
   👉 https://console.anthropic.com

   - 신규: "Sign Up" → 이메일 또는 Google로 가입
   - 기존: "Sign In" → 로그인


STEP 2: API 키 생성

   1. 좌측 메뉴 "API Keys" 클릭
   2. "Create Key" 버튼 클릭
   3. Key Name: SmartTuter Production
   4. "Create Key" 클릭
   5. 생성된 키 복사 (sk-ant-api03-로 시작)

   ⚠️  중요: 이 키는 다시 볼 수 없습니다!
   안전한 곳에 저장하세요 (비밀번호 관리자 권장)


무료 크레딧:
   🎁 가입 시 $5 무료 크레딧 자동 지급
   💬 약 1,000-2,000 대화 가능

3️⃣  Vercel 배포 (7분)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Vercel 접속 및 로그인

   브라우저에서 다음 URL 접속:
   👉 https://vercel.com

   1. "Sign Up" 또는 "Log In" 클릭
   2. "Continue with GitHub" 선택
   3. GitHub 연동 허용


STEP 2: 프로젝트 Import

   1. "Add New..." → "Project" 클릭
   2. "Import Git Repository" 섹션에서 smarttuter 찾기

   저장소가 안 보이는 경우:
   - "Adjust GitHub App Permissions" 클릭
   - Repository access → smarttuter 선택
   - "Save" → Vercel로 돌아가기

   3. smarttuter 옆 "Import" 버튼 클릭


STEP 3: 프로젝트 설정

   Configure Project 화면:

   기본 설정 (자동 감지됨 - 그대로 두기):
   ✓ Framework Preset: Next.js
   ✓ Root Directory: ./
   ✓ Build Command: npm run build
   ✓ Output Directory: .next
   ✓ Install Command: npm install


STEP 4: 환경 변수 설정 (중요!)

   Environment Variables 섹션:

   1. Name: ANTHROPIC_API_KEY
   2. Value: [2단계에서 복사한 API 키 붙여넣기]
      sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
   3. Environment: Production, Preview, Development (모두 선택)
   4. "Add" 버튼 클릭


STEP 5: 배포 시작

   1. "Deploy" 버튼 클릭
   2. 배포 진행 상황 확인 (2-3분 소요)

   진행 단계:
   🔄 Building...    (1-2분)
   🔄 Deploying...   (30초)
   ✅ Ready!         (완료)


STEP 6: 배포 완료!

   성공 메시지:
   🎉 Congratulations!
   Your project is live at: https://smarttuter-xxxx.vercel.app

   "Visit" 버튼 클릭하여 사이트 확인!
