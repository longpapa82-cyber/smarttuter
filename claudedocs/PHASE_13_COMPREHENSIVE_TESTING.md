# Phase 13: 포괄적 테스트 계획

## 📋 테스트 개요
- **목표**: 필기 인식 시스템의 정확도와 성능을 다양한 시나리오에서 검증
- **상태**: 🔄 진행 중
- **날짜**: 2025-11-10

---

## 🎯 테스트 범위

### 1. 학년별 수학 표현식 테스트
#### 초등학교 (1-6학년)
- 기본 사칙연산: `5 + 3`, `12 - 7`, `4 × 6`, `15 ÷ 3`
- 분수: `1/2`, `3/4`, `2 1/3` (대분수)
- 소수: `3.5`, `0.25`, `12.75`
- 간단한 도형: 삼각형, 사각형, 원
- 길이/무게 단위: `5cm`, `3kg`, `2L`

#### 중학교 (1-3학년)
- 음수와 절댓값: `-5`, `|-3|`
- 제곱/제곱근: `x²`, `√25`, `³√8`
- 일차방정식: `2x + 5 = 15`
- 연립방정식: `x + y = 10`, `x - y = 2`
- 부등식: `x > 5`, `2x ≤ 10`
- 좌표: `(3, 5)`, `(-2, 4)`
- 함수: `y = 2x + 3`, `f(x) = x²`

#### 고등학교 (1-3학년)
- 이차방정식: `x² + 5x + 6 = 0`
- 삼각함수: `sin(30°)`, `cos(θ)`, `tan(x)`
- 지수/로그: `2³`, `log₂(8)`, `e^x`
- 미적분: `∫x dx`, `d/dx(x²)`, `lim`
- 행렬: `[1 2; 3 4]`
- 복소수: `3 + 4i`
- 벡터: `→AB`, `|v|`

## 🧪 테스트 케이스 분류

### A. 기본 인식 테스트 (Accuracy)
**목표**: 텍스트 인식 정확도 95% 이상

| 카테고리 | 테스트 케이스 | 기대 결과 |
|---------|-------------|----------|
| 숫자 | `0-9` 각각 | 100% 정확 인식 |
| 알파벳 | `A-Z` 대문자 | 95%+ 정확 인식 |
| 한글 변수 | `ㄱ, ㄴ, ㄷ, 가, 나, 다` | 90%+ 정확 인식 |
| 수학 기호 | `+, -, ×, ÷, =` | 100% 정확 인식 |
| 분수 | `1/2, 3/4, 5/8` | 90%+ 정확 인식 |
| 제곱근 | `√2, √25, ³√8` | 90%+ 정확 인식 |

### B. 후처리 규칙 검증 (Post-processing)
**목표**: 오인식 자동 보정 95% 이상

| 패턴 | 입력 (오인식) | 기대 출력 (보정) | 규칙 |
|------|-------------|---------------|------|
| 숫자→알파벳 | `점 8까지` | `점 B까지` | 8→B (알파벳 문맥) |
| 알파벳→숫자 | `B + 5 = 13` | `8 + 5 = 13` | B→8 (수식 문맥) |
| 한글 오인식 | `CollAl점` | `C점` | CollAl→C |
| 단위 보정 | `거리 10` | `거리 km` | 10→km (거리 문맥) |
| 수학 기호 | `3 × 4` | `3 * 4` | ×→* |
| 분수 띄어쓰기 | `1 / 2` | `1/2` | 띄어쓰기 제거 |

### C. 문맥 기반 보정 테스트 (Context-aware)
**목표**: 문맥 감지 90% 이상

| 문맥 | 입력 | 기대 출력 | 감지 키워드 |
|------|------|----------|-----------|
| 도형 | `삼각형 A8C` | `삼각형 ABC` | 삼각형, 사각형, 원 |
| 거리 | `길이는 10` | `길이는 km` | 거리, 길이, km |
| 좌표 | `( 3 , 5 )` | `(3, 5)` | 좌표, 점, 위치 |

### D. 복합 수식 테스트 (Complex Expressions)
**목표**: 복잡한 수식 85% 이상

| 난이도 | 테스트 케이스 | 난이도 설명 |
|--------|-------------|-----------|
| 중 | `2x + 3 = 11` | 일차방정식 |
| 중 | `√(x² + y²)` | 피타고라스 |
| 고 | `∫(2x + 1)dx` | 적분 |
| 고 | `lim(x→0) sin(x)/x` | 극한 |
| 고 | `[1 2; 3 4]` | 행렬 표기 |

## 🔬 테스트 실행 방법

### 1. 수동 테스트 (Manual Testing)
1. 로컬 서버 실행: `npm run dev`
2. Math Dashboard 접속: `http://localhost:3000/dashboard/math`
3. "필기 인식" 버튼 클릭
4. 테스트 케이스를 캔버스에 작성
5. "인식하기" 클릭
6. 결과 확인 및 기록

### 2. 자동 테스트 스크립트 (향후 구현 예정)
```typescript
// scripts/test-ocr-accuracy.ts
import { geminiVisionOCR } from '@/lib/ocr/gemini-vision-ocr';

const testCases = [
  { input: '7 + 3', expected: '7 + 3' },
  { input: '3√2 + 3/7', expected: '3√2 + 3/7' },
  // ... more cases
];

async function runTests() {
  for (const test of testCases) {
    const result = await geminiVisionOCR(test.input, true);
    const passed = result.text === test.expected;
    console.log(`${passed ? '✅' : '❌'} ${test.input} → ${result.text}`);
  }
}
```

## 🐛 알려진 이슈 및 개선 사항

### 현재 제한사항
1. **복잡한 필기체**: 매우 흘려쓴 글씨는 인식률 저하
2. **특수 기호**: 일부 고등 수학 기호 (적분, 극한) 인식 어려움
3. **작은 글씨**: 매우 작게 쓴 첨자/지수 인식 어려움
4. **겹치는 선**: 여러 번 덧그은 선 인식 어려움

### 개선 계획
1. **사용자 가이드**: 효과적인 필기 작성 방법 안내
2. **예제 제공**: 학년별 모범 필기 예제
3. **재시도 기능**: 인식 실패 시 쉬운 재작성
4. **부분 선택**: 특정 영역만 재인식
