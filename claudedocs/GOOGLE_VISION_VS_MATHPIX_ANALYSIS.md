## 🔍 세부 분석

### 1. Google Vision API

#### ✅ 강점

**1.1 일반 정확도**
- 전체 텍스트: **98.0%** (업계 1위)
- WER: **2.0%** (최저 오류율)
- 인쇄 텍스트: 99.8%

**1.2 한국어/CJK 지원**
- ✅ 한국어 공식 지원 (Text Recognition v2)
- ✅ CJK (중국어/일본어/한국어) 스크립트 전용 최적화
- ✅ 다국어 혼합 텍스트에서도 높은 정확도
- 🎯 **아시아 언어에 특히 강함** (공식 문서 명시)

**1.3 손글씨 인식**
- 손글씨 정확도: **90%+**
- Azure와 비교 시 10% 이상 우수
- 필기체 영어: 85-90%

**1.4 기술적 특징**
- 문맥 기반 인식 (Context-aware)
- 신뢰도 점수 제공 (Confidence score)
- 여러 언어 동시 존재 시에도 정확

#### ❌ 약점

**1.1 수학 수식 인식**
- 수식 전용 최적화 **없음**
- 복잡한 수식: 예상 **60-75%**
- LaTeX 변환 **미지원**
- 분수/지수/적분 등: **70-80%**

**1.2 문서 구조**
- 표/다이어그램: 일반적 수준
- 수식 구조 파싱: 제한적

**1.3 기타**
- STEM 전용 기능 없음
- 화학식 인식 제한적

### 2. Mathpix OCR

#### ✅ 강점

**2.1 수학 수식 인식 (핵심)**
- **수식 정확도: 99%+** (자체 발표)
- 복잡한 수식: **95-99%**
- LaTeX 변환: **완벽 지원**
- 분수/지수/적분/행렬: **95%+**

**2.2 STEM 전용 최적화**
- 수학 기호: 200+ 지원
- 화학식 인식
- 표/다이어그램: 고급
- PDF 수식 추출: 전문

**2.3 다국어 지원**
- ✅ 한국어 공식 지원
- ✅ 세계 주요 언어 전부 지원
- ✅ 다국어 + 수식 혼합 처리

**2.4 시장 점유율**
- 온라인 수학 교육 업계 최다 사용
- 일 1천만+ 이미지 처리
- Photomath, Wolfram 등 채택

#### ❌ 약점

**2.1 일반 텍스트**
- 일반 텍스트 정확도: 데이터 없음
- Google Vision 대비 **불명확**
- 긴 문장 단락: 최적화 약함

**2.2 독립 벤치마크 부재**
- 99% 정확도: **자체 발표**
- 독립적 검증 연구 **없음**
- 학술 논문 벤치마크 **미포함**

**2.3 비용**
- 설정 비용 발생 가능
- 신용카드 등록 필수
- Google 대비 높은 진입장벽
