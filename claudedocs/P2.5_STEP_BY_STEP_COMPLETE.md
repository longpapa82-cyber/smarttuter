#### 구현 내용

##### 1. buildStepByStepFormat 함수 추가

**단계별 풀이 템플릿**:
```markdown
**문제**: [문제 진술]

**풀이 과정**:

### Step 1: [단계 이름]
[설명]
```
[수식/계산]
```

### Step 2: [단계 이름]
[설명]
```
[수식/계산]
```

**최종 답**: [답]

**개념 설명**: [핵심 개념 2-3줄]

**연습 문제**: [비슷한 문제 1개]
```

##### 2. 학년별 예시 제공

**초등학교 예시** (덧셈):
```
문제: 사과 5개와 오렌지 3개가 있습니다. 과일은 모두 몇 개일까요?

### Step 1: 주어진 정보 확인하기
사과가 5개, 오렌지가 3개 있어요.

### Step 2: 더하기로 계산하기
```
5 + 3 = 8
```

**최종 답**: 과일은 모두 8개입니다.

**개념 설명**: 서로 다른 물건들을 합칠 때는 덧셈을 사용해요.

**연습 문제**: 연필 7자루와 지우개 4개가 있어요. 학용품은 모두 몇 개일까요?
```

**중학교 예시** (일차방정식):
```
문제: 2x + 5 = 13을 풀어라.

### Step 1: 등식의 성질 이해하기
양변에 같은 수를 더하거나 빼도 등식은 성립합니다.

### Step 2: 상수항을 우변으로 이동
```
2x + 5 - 5 = 13 - 5
2x = 8
```

### Step 3: 양변을 2로 나누기
```
x = 4
```

**최종 답**: x = 4

**개념 설명**: 일차방정식은 등식의 성질을 이용해 x를 고립시켜 해를 구합니다.
```

**고등학교 예시** (이차방정식):
```
문제: x² - 5x + 6 = 0을 인수분해로 풀어라.

### Step 1: 이차방정식 인식 및 전략 수립
a = 1, b = -5, c = 6
인수분해가 가능한지 확인해봅시다.

### Step 2: 인수분해 (곱해서 6, 더해서 -5)
```
x² - 5x + 6 = (x - 2)(x - 3) = 0
```

### Step 3: 근 구하기
```
x = 2 또는 x = 3
```

**최종 답**: x = 2 또는 x = 3
```

**대학교 예시** (미분방정식):
```
문제: dy/dx = 2x를 풀어라.

### Step 1: 변수 분리형 미분방정식 인식
변수 분리가 가능한 1계 상미분방정식입니다.

### Step 2: 변수 분리
```
dy = 2x dx
```

### Step 3: 양변 적분
```
y = x² + C
```

**최종 답**: y = x² + C
```

##### 3. 사용 조건

**✅ 사용 시기**:
- "풀어주세요", "solve this" 요청
- 명확한 수치/대수 답이 있는 문제
- 단계별 설명이 이해에 도움될 때

**❌ 사용하지 않을 때**:
- 개념 설명만 필요한 경우
- 빠른 질문
- 힌트로 유도할 때 (소크라테스식)

### ✅ Task 2: 풀이 단계 파싱 로직

**목표**: Gemini 응답을 구조화된 데이터로 변환

**파일**: `lib/math/step-parser.ts`

#### 데이터 구조

```typescript
interface MathStep {
  stepNumber: number;    // 단계 번호 (1, 2, 3...)
  title: string;         // 단계 제목 ("주어진 정보 파악")
  explanation: string;   // 설명 텍스트
  equation?: string;     // 수식 (코드 블록 내용)
}

interface ParsedSolution {
  hasProblem: boolean;           // 문제 진술 존재 여부
  problem?: string;              // 문제 텍스트
  hasSteps: boolean;             // 단계 존재 여부
  steps: MathStep[];             // 단계 배열
  finalAnswer?: string;          // 최종 답
  conceptExplanation?: string;   // 개념 설명
  practiceProblems?: string[];   // 연습 문제
}
```

#### 파싱 함수

##### 1. parseStepByStepSolution()

**기능**: Gemini 응답 → ParsedSolution 변환

**파싱 로직**:
```typescript
// 1. 문제 추출
const problemMatch = text.match(/\*\*문제\*\*:\s*(.+?)(?=\n\n)/s);

// 2. 단계 추출 (정규식)
const stepPattern = /###\s*Step\s*(\d+):\s*(.+?)\n([\s\S]*?)(?=###\s*Step|$)/gi;

// 3. 코드 블록에서 수식 추출
const equationMatch = content.match(/```\n?([\s\S]*?)```/);

// 4. 최종 답 추출
const answerMatch = text.match(/\*\*최종 답\*\*:\s*(.+?)(?=\n\n|$)/s);

// 5. 개념 설명 추출
const conceptMatch = text.match(/\*\*개념 설명\*\*:\s*(.+?)(?=\n\n|$)/s);
```

**예시**:
```typescript
const geminiResponse = `
**문제**: 2x + 5 = 13을 풀어라.

### Step 1: 등식의 성질 이해하기
양변에 같은 수를 더하거나 빼도 등식은 성립합니다.

### Step 2: 상수항을 우변으로 이동
\`\`\`
2x = 8
\`\`\`

**최종 답**: x = 4
`;

const parsed = parseStepByStepSolution(geminiResponse);
// {
//   hasProblem: true,
//   problem: "2x + 5 = 13을 풀어라.",
//   hasSteps: true,
//   steps: [
//     { stepNumber: 1, title: "등식의 성질 이해하기", ... },
//     { stepNumber: 2, title: "상수항을 우변으로 이동", equation: "2x = 8", ... }
//   ],
//   finalAnswer: "x = 4"
// }
```

##### 2. hasStepByStepFormat()

**기능**: 텍스트에 단계별 풀이 포함 여부 확인

```typescript
export function hasStepByStepFormat(text: string): boolean {
  const stepPattern = /###\s*Step\s*\d+:/i;
  return stepPattern.test(text);
}
```

### ✅ Task 3: 단계별 애니메이션 UI

**목표**: Photomath 스타일 인터랙티브 단계별 UI

#### UI 구성 요소

##### 1. 진행률 표시

```tsx
{/* 진행 바 */}
<div className="flex gap-1">
  {solution.steps.map((_, index) => (
    <div
      key={index}
      onClick={() => setCurrentStep(index)}
      className={`flex-1 h-2 rounded-full cursor-pointer ${
```

**기능**:
- 각 단계를 막대로 표시
- 완료된 단계: 파란색
- 현재 단계: 약간 더 높음
- 미완료: 회색
- 클릭하여 해당 단계로 이동

##### 2. 자동 재생 기능

```tsx
const handleAutoPlay = () => {
  setIsPlaying(true);
  setCurrentStep(0);

  let step = 0;
  const interval = setInterval(() => {
    step++;
    if (step >= totalSteps) {
      clearInterval(interval);
      setIsPlaying(false);
      return;
    }
    setCurrentStep(step);
  }, 3000); // 3초마다 다음 단계
};
```

**기능**:
- "자동 재생" 버튼 클릭
- 3초마다 자동으로 다음 단계
- 마지막 단계에서 자동 정지
- 재생 중 "정지" 버튼으로 변경

##### 3. 단계 애니메이션

```tsx
<AnimatePresence mode="wait">
  <motion.div
    key={currentStep}
    initial={{ opacity: 0, x: 20 }}
    animate={{ opacity: 1, x: 0 }}
    exit={{ opacity: 0, x: -20 }}
    transition={{ duration: 0.3 }}
  >
    {/* 단계 내용 */}
  </motion.div>
</AnimatePresence>
```

**효과**:
- 단계 전환 시 부드러운 슬라이드
- 오른쪽에서 왼쪽으로 이동
- 0.3초 페이드 인/아웃

##### 4. 단계 카드

```tsx

```

##### 5. 네비게이션 버튼

```tsx
<div className="flex items-center justify-between">

    <ChevronLeft /> 이전 단계
```

**기능**:
- 이전/다음 단계 이동
- 첫 단계에서 "이전" 비활성화

##### 6. 최종 답 표시 (마지막 단계에서만)

**효과**:
- 마지막 단계 도달 시 나타남
- 0.3초 딜레이 후 페이드 인
- 녹색 배경 강조

##### 7. 개념 설명 (마지막 단계에서만)
