## 🔥 P0: 즉시 실행 (1-3일 소요)

### 1. 🎙️ 음성 품질 개선 ⭐ **최우선**
**문제**: 사용자가 "이상한 목소리" 언급, Web Speech API 음질 저하
**영향도**: 매우 높음 (영어 튜터 핵심 기능)
**예상 소요**: 1-2일

**해결 방안**:
```yaml
Option A: Google Cloud TTS (무료 4백만자/월)
  장점:
    - 기업급 품질, 매우 자연스러움
    - 한국어/영어 완벽 지원
    - 감정/강세/속도 제어 (SSML)
  단점:
    - API 키 필요
    - 무료 쿼터 제한
  구현: 2-3시간

Option B: Kokoro (로컬 TTS, 완전 무료) ⭐ 추천
  장점:
    - 100% 무료, 제한 없음
    - 자연스러운 음질
    - 82M 파라미터로 경량
    - 저사양에서도 빠름
  단점:
    - 서버 설정 필요
  구현: 1일

Option C: 하이브리드 (Kokoro + Google TTS)
  전략:
    - 기본: Kokoro (무제한)
    - Premium: Google TTS (고품질)
  구현: 1.5일
```

**실행 계획**:
1. Kokoro 로컬 설치 및 테스트
2. SimpleChatInterface에 TTS 엔진 선택 기능 추가
3. 음성 품질 A/B 테스트
4. 프로덕션 배포

**성공 지표**:
- 음성 자연스러움 사용자 만족도 80% 이상
- TTS 응답 속도 1초 이내

### 3. 🚀 빠른 시작 경로 개선
**문제**: 6단계 온보딩이 길어 이탈률 높음
**영향도**: 높음 (신규 사용자 획득)
**예상 소요**: 1일

**구현 내용**:
```typescript
// /onboarding/quick 페이지 생성
// 2단계만: 학교급 선택 → 과목 선택 → 대시보드

게스트 모드 플로우:
메인 [무료로 시작하기]
→ /onboarding/quick (2단계)
→ /dashboard (게스트)
→ 상단 배너: "회원가입하고 학습 기록 저장하기"
```

**파일**:
- `app/onboarding/quick/page.tsx` (신규)
- `app/(home)/HomeClient.tsx` (수정)
- `lib/user/guest-profile.ts` (신규)

**성공 지표**:
- 온보딩 완료율 60% → 85% 증가
- 신규 사용자 첫 학습 시작까지 시간 5분 → 2분

## 💡 선택 가이드

**"어떤 작업부터 시작할까?"**
1. **사용자 피드백이 있는 문제** → 음성 품질 (P0-1)
2. **빠른 효과, 낮은 복잡도** → 빠른 시작 경로 (P0-3)
3. **핵심 차별화 기능** → 발음 피드백 (P1-4)
4. **장기 경쟁력** → 학습 분석 (P1-7)

**"리소스가 제한적이라면?"**
- P0 3개만 집중 (음성 + 배포 확인 + 빠른 시작)
- 나머지는 사용자 피드백 수집 후 우선순위 재조정

**"빠른 성과를 원한다면?"**
- P0-1 (음성 품질) → 즉시 사용자 만족도 향상
- P0-3 (빠른 시작) → 신규 사용자 획득률 증가
