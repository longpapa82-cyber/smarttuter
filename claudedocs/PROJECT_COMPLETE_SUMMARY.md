## 🎯 프로젝트 개요

### 목표
학교급(초등학교/중학교/고등학교/대학교)과 학년에 맞게 수학과 영어 학습을 튜터링 해주는 AI 기반 웹 서비스

### 핵심 가치
1. **개인화 학습**: 학생의 수준과 감정 상태에 맞춘 맞춤형 교육
2. **과학적 접근**: SM-2 알고리즘, 감정 AI 등 검증된 학습 이론 적용
3. **사용자 친화적**: 직관적인 UI/UX와 최신 트렌드 디자인
4. **포괄적 기능**: 튜터링, 복습, 분석, 리포트까지 통합 솔루션

## 🎨 기술 스택

### Frontend
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **UI Library**: React 19
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **State Management**: Zustand
- **Forms**: React Hook Form

### Backend
- **Runtime**: Node.js (Edge Runtime)
- **API**: Next.js API Routes
- **Authentication**: NextAuth.js
- **AI**: Google Gemini 2.0 Flash

### Audio/Visual
- **TTS**: Web Speech API, Puter.js
- **STT**: Web Speech API
- **Audio Analysis**: Web Audio API
- **Math Rendering**: KaTeX
- **Graphs**: Desmos API

### Storage
- **Client**: LocalStorage, SessionStorage
- **Future**: PostgreSQL/Supabase 준비

## 📈 주요 알고리즘 및 이론

### 1. SuperMemo 2 (SM-2) 알고리즘
```
효율적인 장기 기억 형성
- Easiness Factor (EF): 1.3 ~ 2.5
- Interval 계산: I(1)=1일, I(2)=6일, I(n)=I(n-1)*EF
- 80% 1년 후 기억 유지율 (일반 학습: 20%)
```

### 2. 감정 분석 AI
```
9가지 감정 카테고리 실시간 분석
- Gemini API 텍스트 분석
- Web Audio API 음성 톤 분석
- 감정 강도 및 신뢰도 측정
- 패턴 인식 및 트렌드 분석
```

### 3. 게이미피케이션
```
행동 심리학 기반 동기 부여
- XP 시스템: 작은 성취 보상
- 레벨 시스템: 장기 목표 제공
- 스트릭: 습관 형성 촉진
- 업적: 다양한 학습 행동 유도
```

## 🔧 설치 및 실행

### 필수 요구사항
- Node.js 18+
- npm 또는 yarn
- Google Gemini API Key

### 환경 변수 설정
```env
# .env.local

# Gemini API
GEMINI_API_KEY=your_gemini_api_key
NEXT_PUBLIC_GEMINI_API_KEY=your_gemini_api_key

# NextAuth
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your_nextauth_secret

# Google OAuth
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# GitHub OAuth
GITHUB_ID=your_github_id
GITHUB_SECRET=your_github_secret
```

### 설치 및 실행
```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 프로덕션 실행
npm start
```

### 배포 (Vercel)
```bash
# Vercel CLI 설치
npm i -g vercel

# 배포
vercel

# 프로덕션 배포
vercel --prod
```
