# OCR Feature User Guide - AI Park English Tutor

## 📸 이미지로 영어 공부하기

AI Park의 영어 튜터가 이제 **이미지 속 텍스트를 자동으로 인식**합니다! 교과서, 문제집, 프린트 사진만 찍어도 바로 도움을 받을 수 있습니다.

---

## 🎯 어떤 경우에 사용하나요?

### ✅ 이런 때 유용해요:
- 📚 **교과서 지문이 길 때**: 타이핑하기 귀찮은 긴 지문도 사진 한 장으로 OK
- 📝 **문제집 문제 풀이**: 문제를 일일이 입력할 필요 없이 사진만 찍으세요
- 📋 **학교 프린트물**: 선생님이 나눠주신 프린트도 바로 질문 가능
- 📖 **모르는 단어가 많을 때**: 단어들을 하나씩 입력하지 말고 페이지 전체를 사진으로
- 🎓 **과제 도움**: 숙제하다 막힌 부분, 사진 찍어서 바로 질문하세요

### ❌ 이런 건 어려워요:
- 손글씨 (정자로 쓴 것은 어느 정도 인식 가능)
- 너무 흐릿한 사진
- 빛 반사가 심한 사진
- 구겨진 종이

## 📱 사용 방법 (3단계)

### 1️⃣ 카메라 버튼 클릭
![Image Button Location](English 튜터 채팅창 하단, 마이크 버튼 옆 카메라 아이콘)

**위치**: 영어 튜터 채팅창 하단, 입력창 옆
**아이콘**: 📷 카메라 모양

### 2️⃣ 이미지 업로드
두 가지 방법 중 선택:

**방법 A: 드래그 앤 드롭**
```
사진 파일을 마우스로 끌어다 놓기
```

**방법 B: 파일 선택**
```
1. 업로드 영역 클릭
2. 파일 선택 창에서 사진 선택
3. 확인 클릭
```

**지원 형식**: JPG, PNG, WebP, BMP
**최대 크기**: 10MB (권장: 5MB 이하)

### 3️⃣ 인식 결과 확인 및 질문
```
✅ 텍스트 인식 완료
   신뢰도: 92.5%
   독해 문제

📝 인식된 텍스트:
   According to the passage, what is the main idea...

   24개 단어 • 3줄

[다시 찍기]  [튜터에게 질문하기 →]
```

**"튜터에게 질문하기"** 버튼을 누르면 자동으로 튜터에게 전송됩니다!

## 🧠 AI 기능

### 자동 콘텐츠 분류
AI가 이미지 속 텍스트를 자동으로 분류합니다:

| 분류 | 설명 | 예시 키워드 |
|------|------|------------|
| 📘 독해 문제 | Reading comprehension | "according to the passage", "main idea" |
| 📗 어휘 문제 | Vocabulary | "synonym", "antonym", "definition" |
| 📙 문법 문제 | Grammar | "correct form", "verb tense", "fill in the blank" |
| 📓 일반 텍스트 | General text | 기타 모든 텍스트 |

### 신뢰도 점수
- **90-100%**: 🟢 매우 정확 (거의 완벽)
- **80-89%**: 🟡 정확 (일부 수정 필요할 수 있음)
- **70-79%**: 🟠 보통 (확인 권장)
- **70% 미만**: 🔴 낮음 (다시 찍기 권장)

### 자동 최적화
- **이미지 압축**: 큰 사진도 자동으로 최적화 (2-5초 처리)
- **성능 최적화**: 1920x1080 해상도로 자동 조정
- **배터리 절약**: 휴대폰 배터리를 적게 사용합니다

## 💡 사진 잘 찍는 법

### ✅ 좋은 예
```
📸 선명하고 밝은 사진
   - 충분한 조명
   - 흔들림 없이
   - 텍스트가 화면 중앙
   - 적당한 거리 (너무 가깝지도 멀지도 않게)
```

### ❌ 나쁜 예
```
📸 흐릿하거나 어두운 사진
   - 조명 부족
   - 손 떨림
   - 빛 반사 (유리/코팅된 종이)
   - 너무 기울어진 각도
```

### 📸 촬영 팁
1. **조명**: 자연광 또는 밝은 실내등 아래
2. **각도**: 종이와 카메라를 평행하게
3. **거리**: 텍스트가 화면의 70-80% 차지하도록
4. **초점**: 텍스트에 자동 초점 맞추기
5. **안정**: 양손으로 휴대폰을 잡거나 책상에 고정

## 🔧 문제 해결

### "텍스트 인식에 실패했습니다"
**원인**:
- 사진이 너무 흐림
- 조명이 부족함
- 텍스트가 너무 작음
- 손글씨 (인쇄체만 지원)

**해결 방법**:
1. 밝은 곳에서 다시 촬영
2. 카메라를 가까이 대서 텍스트를 크게
3. 손 떨림 방지 (책상에 고정하거나 3초 후 촬영)
4. 인쇄된 자료 사용

### 인식 시간이 너무 오래 걸려요
**정상 범위**: 2-5초
**오래 걸리는 경우**: 5-10초

**원인**:
- 이미지 크기가 매우 큼 (>10MB)
- 인터넷 연결이 느림 (초기 모델 로딩 시)
- 휴대폰/컴퓨터 성능이 낮음

**해결 방법**:
1. 사진 크기를 줄여서 촬영 (화질 설정 조정)
2. 첫 사용 시 Wi-Fi 환경 권장 (모델 다운로드)
3. 다른 앱 종료하여 메모리 확보

### 일부 단어가 잘못 인식돼요
**흔한 경우**:
- 특수 문자 (%, $, @)
- 숫자와 알파벳 혼동 (0과 O, 1과 I)
- 이탤릭체나 굵은 글씨

**해결 방법**:
1. "다시 찍기"로 재촬영
2. 인식 결과 확인 후 직접 수정하여 재전송
3. 해당 부분만 다시 타이핑해서 보충 질문

## 📊 성능 및 한계

### 인식 성능
| 항목 | 성능 |
|------|------|
| 정확도 | 85-95% (선명한 이미지 기준) |
| 처리 시간 | 2-5초 (일반적인 숙제 사진) |
| 지원 언어 | 영어 (기본), 100+ 언어 |
| 파일 형식 | JPG, PNG, WebP, BMP |
| 최대 파일 크기 | 10MB |

### 잘 인식하는 것
✅ 인쇄된 교과서 텍스트
✅ 타자로 친 문서
✅ 깨끗한 프린트물
✅ 명조체, 고딕체, Arial, Times New Roman

### 인식이 어려운 것
❌ 손글씨 (부분적으로만 인식 가능)
❌ 매우 작은 글씨 (<10pt)
❌ 손상된 문서
❌ 복잡한 표나 그래프
❌ 워터마크가 있는 이미지

## 🎓 학습 시나리오 예시

### 시나리오 1: 독해 문제 풀이
```
상황: 고등학교 1학년, 영어 독해 문제집 풀다가 막힘

1. 문제집 해당 페이지 사진 촬영
2. 카메라 버튼 클릭 → 사진 업로드
3. AI가 자동 인식: "📘 독해 문제" 분류
4. "튜터에게 질문하기" 클릭
5. 튜터 응답:
   "이 지문의 핵심은 'climate change'의 영향이네요.
    문단 2에서 저자가 주장하는 바는..."
```

### 시나리오 2: 어휘 학습
```
상황: 중학교 3학년, 단어장 페이지에 모르는 단어가 많음

1. 단어장 페이지 전체 촬영
2. 업로드 후 AI 인식: "📗 어휘 문제"
3. 인식된 단어 리스트 확인
4. 튜터에게 자동 전송
5. 튜터 응답:
   "이 단어들은 모두 '감정'과 관련된 형용사예요.
    enthusiastic은 '열정적인'이라는 뜻으로..."
```

### 시나리오 3: 문법 설명
```
상황: 고등학교 2학년, 문법 문제 설명이 이해 안 됨

1. 문제와 해설 부분 함께 촬영
2. 업로드 → "📙 문법 문제" 자동 분류
3. 튜터에게 전송
4. 튜터 응답:
   "이 문제는 '분사구문'에 관한 거예요.
    'Having finished'가 왜 정답인지 단계별로 설명할게요..."
```

## 🌟 활용 팁

### 효율적인 학습을 위한 팁
1. **전체 페이지보다 문제별로**: 한 번에 많은 문제를 찍기보다 하나씩 차근차근
2. **질문 추가하기**: 인식된 텍스트에 "이 부분이 이해가 안 돼요" 같은 구체적인 질문 추가
3. **복습에 활용**: 틀린 문제를 사진으로 찍어 나중에 다시 질문
4. **그룹 스터디**: 친구들과 함께 문제 찍어서 공유

### 이런 경우엔 타이핑이 더 빠를 수 있어요
- 단어 1-2개만 물어볼 때
- 매우 짧은 문장 (5단어 이하)
- 간단한 문법 규칙 질문
