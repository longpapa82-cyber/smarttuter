#### 1. TopNavigation 컴포넌트 재작성

**파일**: `components/navigation/TopNavigation.tsx` (~360 lines)

**주요 개선사항**:
- ✅ Phase 14 계획서 스펙에 맞게 완전 재작성
- ✅ 깔끔한 컴포넌트 분리: NavItem, NavDropdown, ProfileDropdown, MobileNav
- ✅ 1-클릭 튜터 접근: 영어 튜터 / 수학 튜터 직접 링크
- ✅ 대시보드 드롭다운: 전체 / 영어 / 수학 대시보드
- ✅ Desktop + Mobile 반응형 완벽 지원
- ✅ 알림 아이콘 + 프로필 드롭다운
- ✅ Framer Motion 애니메이션 적용

**기술 스펙**:
```typescript
// Desktop GNB 구조
<nav>
  좌측:
    - 모바일 햄버거 메뉴
    - 로고 (SmartTutor)
    - NavItem: 영어 튜터
    - NavItem: 수학 튜터
    - NavDropdown: 대시보드
      - 전체 대시보드
      - 영어 대시보드
      - 수학 대시보드

  우측:
    - 알림 아이콘 (Bell)
    - 프로필 드롭다운
      - 프로필 편집
      - 설정
      - 학습 리포트
      - 로그아웃
</nav>

// Mobile GNB (사이드바)
<MobileNav>
  - 홈
  - 영어 튜터
  - 수학 튜터
  - 전체 대시보드
  - 영어 대시보드
  - 수학 대시보드
  - 프로필
  - 설정
</MobileNav>
```

**스타일**:
- Sticky top-0 z-40
- bg-white/95 backdrop-blur-md
- Active state: text-primary-600 bg-primary-50
- Hover: bg-gray-50
- Mobile sidebar: w-72, spring animation
