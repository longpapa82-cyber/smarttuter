## 🚀 빠른 시작

```bash
# 클론 및 설치
git clone https://github.com/longpapa82-cyber/smarttuter.git
cd smarttuter
npm install

# 환경 변수 설정
echo "ANTHROPIC_API_KEY=your_key_here" > .env.local

# 개발 서버 실행
npm run dev
```

브라우저에서 http://localhost:3000 접속
